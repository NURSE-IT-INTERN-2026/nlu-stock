Key Architecture Decisions
DecisionRationale
ไม่ใช้ next-authjose JWT เบากว่า — 3 roles เท่านั้น ไม่ต้อง OAuth / social login
ไม่ใช้ ReduxReact Context เพียงพอ — cart + filters ไม่ซับซ้อน bundle เล็กกว่า
Prisma > raw SQLtype-safe queries, auto-complete, versioned migration, $transaction
PostgreSQL > MySQLarray fields (images[]), enum types, JSON queries, composite unique
shadcn/ui > MUIcopy-paste ไม่ lock-in, Tailwind-native, ปรับแก้เต็มที่
Dual Tracking Modelครุภัณฑ์ → SubItem/subCode, วัสดุ → quantity + Lot, schema เดียว
