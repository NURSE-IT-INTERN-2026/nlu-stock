# playwright-bdd — 23 งาน × scenario (Gherkin, UI-level)

> **สถานะ: สร้างเสร็จแล้ว** — ไฟล์จริงอยู่ที่ `e2e/features/*.feature` (1 Feature/ไฟล์) + steps ที่ `e2e/steps/`
> รันด้วย `npm run test:e2e` (เปิด Chrome ให้ดูทุกครั้ง — ปิดด้วย `HEADLESS=1`) เอกสารนี้เหลือเป็น draft อ้างอิง
> ข้อความบางอันในนี้ถูกปรับตาม label จริงตอนเขียน steps แล้ว (เช่น "รับเข้าใหม่" → "นำเข้าคลัง")

ร่างก่อนเขียนโค้ด อ้างอิง 24 งานจาก `docs/html/nlu-stock-architecture.html` ตัด "นำเข้า CSV" ออก (import ให้ user เอง) เหลือ **23**
ทุก step เขียนถึงระดับสิ่งที่ผู้ใช้เห็นบนจอ: ช่องกรอก ปุ่ม แท็บ คอลัมน์ ตัวเลขบนการ์ด ข้อความแจ้ง — ชื่อทุกอย่างดึงจากโค้ดจริงไม่ใช่ชื่อสมมติ

กติกา:
- Scenario แรกของแต่ละ Feature = happy path (ตัวนับ 23)
- `edge:` = ควรมีเพิ่ม ยังไม่สัญญาเขียนหมด
- ข้อมูลอ้างอิงด้วย `code` ไม่ใช่ id / steps เรียก helpers จาก `e2e/fixtures.ts` เดิม
- ตรวจผลที่หน้าจอเป็นหลัก ข้ามไป DB เฉพาะ edge ที่จอบอกไม่ได้ (เช่น ค่าล็อตใน DB)
- ของที่จำลองขึ้นมาต้องมี **สถานที่จัดเก็บ** เสมอ — wizard เพิ่มรายการบังคับกรอก อาคาร/ชั้น/ห้อง ก่อนกดถัดไป
  รายการที่ไม่มีจึงเป็นของที่เกิดขึ้นจริงไม่ได้ และ dialog คืนเข้าคลังจะขึ้นว่า "ยังไม่ได้ตั้งสถานที่จัดเก็บให้พัสดุนี้"

## ก — ก่อนของเข้าคลัง

### 1. เข้าสู่ระบบ

```gherkin
Feature: เข้าสู่ระบบ
  ไม่มีการสมัครสมาชิก รายชื่อถูกตั้งไว้ล่วงหน้า

  Scenario: อีเมลที่อยู่ในรายชื่อเข้าใช้ได้
    Given ฉันเปิดหน้า /login
    And  อีเมลของผู้ดูแลระบบถูกตั้งสิทธิ์ไว้ล่วงหน้า
    When ฉันกรอกอีเมลในช่อง "email@example.com" แล้วกดเข้าสู่ระบบ
    Then ฉันจะเห็นหน้าแดชบอร์ด
    And  ฉันจะเห็นเมนู "ตั้งค่า" ในแถบข้าง

  Scenario: edge — อีเมลนอกทะเบียนเข้าไม่ได้
    When ฉันกรอกอีเมลที่ไม่อยู่ในรายชื่อแล้วกดเข้าสู่ระบบ
    Then ฉันจะเห็นข้อความว่าเข้าไม่ได้ และยังอยู่หน้า /login

  Scenario: edge — สิทธิ์ stockOnly ไม่เห็นเมนูตั้งค่า
    Given ฉันเข้าสู่ระบบด้วยบัญชีสิทธิ์ stockOnly
    Then ฉันจะไม่เห็นเมนู "ตั้งค่า" ในแถบข้าง
    And  ฉันจะไม่เห็นเมนู "รับเข้า-คืนพัสดุ" และ "บำรุงรักษา"
```

หมายเหตุ: ปุ่ม "เข้าสู่ระบบด้วยบัญชีมหาวิทยาลัย" (CMU OAuth) ต้องมี stub ก่อนจึงยังไม่อยู่ใน draft

### 2. เพิ่มพัสดุรายการใหม่

```gherkin
Feature: เพิ่มพัสดุรายการใหม่ (wizard "เพิ่มพัสดุใหม่" ในหน้าตั้งค่า)

  Scenario: สร้างรายการที่นับรายชิ้น
    Given ฉันเปิดหน้าตั้งค่าแล้วกดปุ่ม "เพิ่มพัสดุใหม่"
    And  มีหมวดของคงทนอยู่แล้วในระบบ
    When ฉันเลือกหมวดของคงทน กรอกชื่อและหน่วยนับ แล้วตั้งให้นับรายชิ้น 3 ชิ้น
    And  ฉันกดปุ่ม "สร้าง"
    Then ฉันจะเห็นรายการใหม่ในตารางพร้อมรหัสรูปแบบ NLU-XXX-001
    And  ฉันจะเห็นเลขชิ้นย่อย C01 C02 C03 เมื่อเปิดแท็บชิ้นย่อยของรายการนี้
    And  ฉันจะเห็นวันตรวจนับถัดไปและวันบำรุงรักษาถัดไปในแท็บภาพรวม

  Scenario: edge — สิ้นเปลือง 1 ชิ้นไม่มีหน้าท้ายรหัส
    When ฉันสร้างรายการของสิ้นเปลือง 1 ชิ้น
    Then ฉันจะเห็นรหัสเป็น base code ที่ไม่มี -C0n ต่อท้าย
```

### 3. รับของเข้าคลัง

```gherkin
Feature: รับของเข้าคลัง (หน้า "รับเข้า-คืนพัสดุ" แท็บ "รับเข้าใหม่")

  Scenario: รับเข้าสิ้นเปลืองพร้อมล็อตและราคา
    Given ฉันเปิดหน้า "รับเข้า-คืนพัสดุ" แล้วเลือกแท็บ "รับเข้าใหม่"
    And  รายการของสิ้นเปลือง X มียอด 0
    When ฉันค้นหา X ในช่อง "ค้นหาพัสดุเพื่อเพิ่ม..." แล้วเพิ่มเข้าใบรับ
    And  ฉันกรอกจำนวน 10 เลขล็อต และราคาต่อหน่วย
    And  ฉันกดปุ่มบันทึกใบรับเข้า
    Then ฉันจะเห็นข้อความยืนยันว่าบันทึกแล้ว
    And  ฉันจะเห็นว่า X มียอดคงเหลือ 10 เมื่อเปิดหน้า "รายการพัสดุ"

  Scenario: edge — ไม่ระบุล็อตก็รับได้
    When ฉันบันทึกใบรับเข้าโดยไม่กรอกเลขล็อต
    Then ฉันจะเห็นว่ายอดคงเหลือเพิ่มขึ้นตามจำนวนที่กรอก
```

### 4. แก้ใบรับเข้าย้อนหลัง

```gherkin
Feature: แก้ใบรับเข้าย้อนหลัง

  Scenario: แก้จำนวนในใบรับเข้า
    Given มีใบรับเข้าของ X จำนวน 10 ชิ้นบันทึกไว้เมื่อวาน
    When ฉันเปิดรายละเอียดใบรับเข้าใบนั้น แล้วแก้จำนวนเป็น 15
    And  ฉันกดบันทึก
    Then ฉันจะเห็นว่า X มียอดคงเหลือ 15 บนหน้า "รายการพัสดุ"
    And  ฉันจะเห็นแถวประวัติของการแก้ไขในแท็บ "ประวัติ" ของ X

  Scenario: edge — แก้จนต่ำกว่าที่เบิกไปแล้วต้อง block
    Given ใบรับเข้า 10 ชิ้น และมีการเบิกไปแล้ว 8
    When ฉันแก้จำนวนในใบรับลดเหลือ 5 แล้วกดบันทึก
    Then ฉันจะเห็นข้อความปฏิเสธจากระบบ และยอดไม่เปลี่ยน
```

### 5. หาของที่ต้องการ

```gherkin
Feature: ค้นหาพัสดุ (หน้า "รายการพัสดุ")

  Scenario: ค้นด้วยชื่อหรือรหัส
    Given ฉันเปิดหน้า "รายการพัสดุ"
    When ฉันพิมพ์ชื่อรายการลงในช่อง "ค้นหารหัส / ชื่อพัสดุ…"
    Then ฉันจะเห็นรายการที่ชื่อตรงในตาราง
    And  เมื่อฉันกดที่แถวนั้น ฉันจะเห็นหน้ารายละเอียดของรายการ

  Scenario: edge — ค้นด้วยคำพ้องความหมาย (search-ai)
    When ฉันค้นหาด้วยคำที่ไม่ใช่ชื่อจริงแต่ใกล้เคียงความหมาย
    Then ฉันจะเห็นรายการที่เกี่ยวข้องขึ้นมาในผลค้นหา
```

### 6. เบิกใช้ — ของสิ้นเปลือง

```gherkin
Feature: เบิกใช้ของสิ้นเปลือง (หน้า "เบิก-ยืมพัสดุ" → ตะกร้า → "ตรวจสอบและยืนยัน")

  Scenario: เบิกผ่านตะกร้าแล้วยืนยัน
    Given รายการสิ้นเปลือง X มี 2 ล็อต ล็อตเก่า 5 ชิ้น ล็อตใหม่ 5 ชิ้น
    And  ฉันเปิดหน้า "เบิก-ยืมพัสดุ"
    When ฉันพิมพ์รหัส X ในช่องค้นหา แล้วกดปุ่มใส่ตะกร้า จำนวน 3 ชิ้น
    And  ฉันเปิดตะกร้า แล้วกด "ตรวจสอบและยืนยัน"
    And  ฉันกดยืนยันการเบิกในหน้ายืนยัน
    Then ฉันจะเห็นข้อความว่าเบิกสำเร็จ
    And  ฉันจะเห็นว่า X มียอดคงเหลือ 7 บนหน้า "รายการพัสดุ"
    And  ฉันจะเห็นแถวการเบิกครั้งนี้ในแท็บ "ประวัติ" ของ X

  Scenario: edge — เบิกเกินสต็อกต้อง block
    When ฉันใส่ตะกร้ามากกว่ายอดที่มีแล้วกดยืนยัน
    Then ฉันจะเห็นข้อความ "ใส่ตะกร้าไม่สำเร็จ" หรือข้อความเตือนจากตะกร้า
    And  ยอดของ X ไม่เปลี่ยนแปลง
```

### 7. ยืม — ของคงทนที่ต้องได้คืน

```gherkin
Feature: ยืมของคงทน (หน้า "เบิก-ยืมพัสดุ" โหมด "ยืม-คืน ตาม Code")

  Scenario: ยืมชิ้นที่ว่างพร้อมกำหนดคืน
    Given รายการนับรายชิ้น X มีชิ้นย่อย C01 ว่างอยู่
    And  ฉันเปิดหน้า "เบิก-ยืมพัสดุ" เลือกโหมด "ยืม-คืน ตาม Code"
    When ฉันค้นหา X แล้วเลือกชิ้น C01 ใส่ตะกร้า
    And  ฉันกรอกช่อง "กำหนดคืน" ในตะกร้า
    And  ฉันกด "ตรวจสอบและยืนยัน" แล้วยืนยันการยืม
    Then ฉันจะเห็นข้อความว่ายืมสำเร็จ
    And  ฉันจะเห็นสถานะชิ้น C01 เป็น "ยืมอยู่" ในแท็บชิ้นย่อยของ X
    And  ฉันจะเห็นชิ้นนี้อยู่ในรายการค้างส่งคืนบนหน้าแดชบอร์ด

  Scenario: edge — ยืมชิ้นที่ถูกยืมอยู่ต้อง block
    Given ชิ้นย่อย C02 สถานะ "ยืมอยู่" อยู่แล้ว
    When ฉันพยายามเลือก C02 ใส่ตะกร้าอีกครั้ง
    Then ฉันจะไม่สามารถเลือก C02 ได้ หรือเห็นข้อความว่าชิ้นไม่ว่าง
```

### 8. ตั้งใช้ในห้อง


### 9. ชุดเบิกสำเร็จรูป

### 12. คืนมาแล้วพบว่าพัง

```gherkin
Feature: คืนของที่พบว่าชำรุด (ระบุสภาพรายชิ้นตอนรับคืน)

  Scenario: คืนพร้อมสภาพชำรุด
    Given ชิ้นย่อย C01 ถูกยืมอยู่
    When ฉันรับคืนผ่านแท็บ "รับคืนจากใบยืม" โดยเลือกสภาพชิ้นเป็นชำรุด
```
