⑧ อ่านยังไง

items = ศูนย์กลาง — ทุกตาราง transaction (เบิก/รับ/ปรับ/บำรุง/log) อ้างกลับมาที่ items.id

สามชั้นหลัก: Master (categories/locations/units) → items → รายละเอียด (sub_items/lots/kit_components) → transactions (dispense/receive/adjustment/maintenance/log)

CASCADE (ลบทิ้งตาม): ลบ item → sub_items/lots/kit_components หายด้วย · RESTRICT: มีการเบิกแล้วลบ item ไม่ได้ · SET NULL: ลบ lot/sub_item → ระเบียนเก่ายังอยู่แค่เปลี่ยนเป็น null
