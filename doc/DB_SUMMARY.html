① เช็ค Ref Code ที่ "ประเภท" — ได้ใช้มั้ย?

สรุป: รหัสสินค้า (code) ใช้ หมวด enum (7 ค่า) เป็น prefix — ไม่ได้ใช้ "ประเภท" (CategoryType / ตาราง categories)

ฟอร์แมต = NLU-{ENUM}-{NNN} (+ optional -SNN สำหรับ set BOOK/TOY)
ENUM ∈ KRU | ELE | BOOK | TOY | DUR | CON | KIT  ·  logic อยู่ที่ src/app/api/items/suggest-code/route.ts

ดังนั้น: หากอยากให้ ref code อิง "ประเภท" (เช่น หุ่นทางสูติศาสตร์) ต้องเพิ่มฟิลด์ code/prefix ในตาราง categories ก่อน — ตอนนี้ตาราง categories ไม่มีฟิลด์รหัส (มีแค่ id/name/category/description/sortOrder)
