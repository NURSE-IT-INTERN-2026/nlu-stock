1

เบิก–ยืมพัสดุ

หยิบของใส่ตะกร้า ระบุผู้ยืม แล้วยืนยัน — ระบบตัดของออกจากสต๊อกให้อัตโนมัติ

พัสดุในระบบมี 3 แบบ และแต่ละแบบตัดสต๊อกไม่เหมือนกัน:
• วัสดุสิ้นเปลือง (เช่น สำลี น้ำยา) — ตัดจาก “ล็อต” ที่ใกล้หมดอายุก่อนเสมอ
• วัสดุคงทนแบบนับจำนวน (เช่น อุปกรณ์ทั่วไป) — ลดจำนวนคงเหลือลง
• ครุภัณฑ์รายชิ้น (เช่น หุ่นฝึก เครื่องมือมีเลขครุภัณฑ์) — จับจองเป็นรายชิ้น ทำเครื่องหมายว่า “ถูกยืม”

    A([เจ้าหน้าที่ค้นหาพัสดุ]) --> B[เพิ่มลงตะกร้า]
    B --> C[เลือกจำนวน / เลือกชิ้น
ระบุผู้ยืม และกำหนดคืน ถ้ามี]
    C --> D{กดยืนยันการเบิก}
    D --> E{ของในคลังพอไหม?}
    E -->|ไม่พอ| E1[[แจ้งเตือน ทำรายการไม่ได้]]
    E -->|พอ| F{เป็นพัสดุแบบไหน?}
    F -->|วัสดุสิ้นเปลือง| G1[ตัดจากล็อตที่ใกล้หมดอายุก่อน]
    F -->|นับจำนวน| G2[ลดจำนวนคงเหลือ]
    F -->|ครุภัณฑ์รายชิ้น| G3[ทำเครื่องหมายชิ้นนั้นว่า ถูกยืม]
    G1 --> H([บันทึกประวัติการเบิก])
    G2 --> H
    G3 --> H
✅
ผลลัพธ์: ของถูกหักออกจากสต๊อกทันที และมีประวัติการเบิกบันทึกไว้ — ไปแสดงที่ หน้าแรก (กราฟ/รายการเบิกล่าสุด), เมนูรายงาน “ประวัติการเบิก”, และหน้ารายละเอียดพัสดุ
2

ยืนยันการเบิก

ทุกอย่างในการกดยืนยันครั้งเดียว จะสำเร็จทั้งหมดหรือไม่สำเร็จทั้งหมด

เมื่อกด “ยืนยัน” ระบบจะทำงานแบบ ทั้งหมดหรือไม่ทำเลย — ถ้ามีของสักรายการในตะกร้าไม่พอ ระบบจะยกเลิกทั้งบิลและไม่ตัดสต๊อกอะไรเลย เพื่อกันไม่ให้ตัวเลขคลังเพี้ยน และกันของติดลบเวลามีคนเบิกพร้อมกัน

    A([กดยืนยันการเบิก]) --> B[ตรวจทุกรายการในตะกร้า]
    B --> C{มีรายการไหนของไม่พอ
หรือชิ้นนั้นถูกยืมไปแล้ว?}
    C -->|มี| D[[ยกเลิกทั้งบิล
ไม่ตัดสต๊อกใด ๆ · แจ้งเหตุผล]]
    C -->|ไม่มี| E[บันทึกใบเบิกทุกบรรทัด]
    E --> F[ตัดสต๊อกตามชนิดพัสดุ]
    F --> G([สำเร็จ · ล้างตะกร้า · กลับหน้าเบิก])
✅
ผลลัพธ์: ได้ใบเบิก 1 รายการที่จับกลุ่มทุกบรรทัดไว้ด้วยกัน (1 การยืม) เพื่อให้ตอนรับคืนเห็นเป็น “การ์ดเดียว” ไม่กระจัดกระจาย
3

รับเข้าพัสดุ

เพิ่มของเข้าคลัง — ของใหม่หรือเติมของเดิม

หน้ารับเข้าใช้เพิ่มจำนวนของในคลัง ระบบจะขอข้อมูลต่างกันตามชนิดพัสดุ:
• วัสดุสิ้นเปลือง ต้องระบุ “เลขล็อต” และวันหมดอายุ (ถ้ามีล็อตเดิมอยู่แล้วจะเติมเข้าไป)
• ครุภัณฑ์รายชิ้น ต้องระบุ “รหัสรายชิ้น” ให้ครบตามจำนวนที่รับเข้า 
flowchart TD
    A([ค้นหาพัสดุที่จะรับเข้า]) --> B[ใส่จำนวนที่รับเข้า]
    B --> C{เป็นพัสดุแบบไหน?}
    C -->|วัสดุสิ้นเปลือง| D1[ใส่เลขล็อต + วันหมดอายุ]
    C -->|ครุภัณฑ์รายชิ้น| D2[ใส่รหัสรายชิ้นให้ครบจำนวน]
    C -->|นับจำนวน| D3[ระบุจำนวนอย่างเดียว]
    D1 --> E{กดบันทึกรับเข้า}
    D2 --> E
    D3 --> E
    E --> F[เพิ่มจำนวนคงเหลือในคลัง]
    F --> G([บันทึกประวัติการรับเข้า])
✅
ผลลัพธ์: จำนวนคงเหลือเพิ่มขึ้นทันที มีประวัติการรับเข้า ไปแสดงที่รายงาน “ประวัติการรับเข้า” และหน้ารายละเอียดพัสดุ
4

รับคืนพัสดุ

รับของที่ยืมไปกลับเข้าคลัง พร้อมระบุสภาพ ปกติ / ชำรุด / สูญหาย

หน้ารับคืนจะแสดง “รายการที่ยืมค้าง” เป็นการ์ดต่อ 1 การยืม เจ้าหน้าที่เลือกการยืมที่จะรับคืน แล้วระบุสภาพของแต่ละชิ้น/แต่ละจำนวน:
ปกติ → กลับเข้าคลัง ใช้ต่อได้ ชำรุด → เข้าคิวซ่อม สูญหาย → ตัดออกจากคลัง
ใหม่ เดิมการคืน “แบบนับจำนวน” เลือกได้แค่ปกติอย่างเดียว ตอนนี้ระบุ ชำรุด/สูญหาย พร้อมจำนวน ได้แล้ว และถ้ามีของไม่ปกติ ต้องแนบรูปหลักฐาน ก่อนจึงจะบันทึกได้ 
flowchart TD
    A([เปิดหน้ารับคืน]) --> B[เลือกการยืมที่จะรับคืน]
    B --> C{ประเภทพัสดุ}

    C -->|ครุภัณฑ์รายชิ้น| D1[ติ๊กเลือกชิ้น + เลือกสภาพแต่ละชิ้น]
    C -->|นับจำนวน| D2[ใส่จำนวนที่คืน
ติ๊กมีชำรุด/สูญหาย + ใส่จำนวน]

    D1 --> E{มีของไม่ปกติไหม?}
    D2 --> E
    E -->|มี| F[ต้องแนบรูปหลักฐานก่อน]
    E -->|ไม่มี| G[กดบันทึกการคืน]
    F --> G

    G --> H{สภาพของแต่ละส่วน}
    H -->|ปกติ| I1[กลับเข้าคลัง พร้อมใช้งาน]
    H -->|ชำรุด| I2[เข้าคิวซ่อม · เปิดใบซ่อมให้อัตโนมัติ]
    H -->|สูญหาย| I3[ตัดออกจากคลัง บันทึกว่าสูญหาย]

    I1 --> J([อัปเดตประวัติ · ปิดการยืมเมื่อคืนครบ])
    I2 --> J
    I3 --> J
🔧
ของชำรุดไปไหน? ใหม่ ไม่ว่าจะเป็นครุภัณฑ์รายชิ้นหรือแบบนับจำนวน พอทำเครื่องหมาย “ชำรุด” ระบบจะ เปิดใบซ่อมให้อัตโนมัติ ไปโผล่ที่หน้า “บำรุงรักษา” และรายงานประวัติการซ่อม จึงไม่มีของชำรุดตกหล่นหายไปจากสายตา

เตือนเมื่อเกินกำหนดคืน ใหม่

ของที่ยืมเลยวันกำหนดคืน จะถูกนับขึ้นที่กระดิ่งแจ้งเตือนอัตโนมัติ

ระบบจะตรวจเป็นระยะว่ามีการยืมไหนเลยวันกำหนดคืนแล้วบ้าง ถ้ามีจะ นับรวมขึ้นที่ตัวเลขกระดิ่งแจ้งเตือน เหมือนกับ “เกินกำหนดซ่อม” และ “สต๊อกต่ำ” ทำให้เจ้าหน้าที่เห็นได้จากทุกหน้า ไม่ต้องคอยเปิดเช็คเอง

    A([ระบบตรวจเป็นระยะทุก ~5 นาที]) --> B{มีการยืมที่เลยกำหนดคืนไหม?}
    B -->|ไม่มี| B0([ไม่ขึ้นแจ้งเตือน])
    B -->|มี| C[นับจำนวนขึ้นที่กระดิ่งแจ้งเตือน]
    C --> D[คลิกกระดิ่ง เปิดหน้าการแจ้งเตือน]
    D --> E[คลิกหัวข้อ เกินกำหนดคืน]
    E --> F([พาไปหน้ารับคืน
กรองเฉพาะรายการที่เกินกำหนดให้ทันที])
